# Aletheia हिंदी क्विक-स्टार्ट गाइड

यह गाइड आपको **Aletheia** — भारतीय शेयरों और क्रिप्टो के लिए निजी रिसर्च डेस्क — का डेस्कटॉप ऐप इंस्टॉल करने और अपना पहला विश्लेषण चलाने का तरीका चरण-दर-चरण दिखाता है। हर चरण में सटीक फ़ाइल नाम, कमांड और अपेक्षित परिणाम दिए गए हैं। पैकेज्ड ऐप फ़िलहाल केवल Windows के लिए है।

## 1. इंस्टॉल करना

1. **[नवीनतम रिलीज़ पेज](https://github.com/AbsSadhu/Aletheia/releases/latest)** खोलें।
   - पेज पर नीचे **Assets** (एसेट्स) अनुभाग खोलें।
   - नीचे दी गई दो फ़ाइलें डाउनलोड करें और दोनों को एक ही फ़ोल्डर (जैसे Downloads) में रखें:
     - `ALETHEIA_0.2.0_x64-setup.exe` (इंस्टॉलर)
     - `SHA256SUMS.txt` (चेकसम फ़ाइल)
   - **अपेक्षित परिणाम:** आपके Downloads फ़ोल्डर में ये दोनों फ़ाइलें मौजूद हैं।

2. **डाउनलोड सत्यापित करें** (कुछ सेकंड लगते हैं)। **PowerShell** खोलें, उस फ़ोल्डर में जाएँ जहाँ आपने फ़ाइलें रखी हैं, और यह कमांड चलाएँ:

   ```powershell
   Get-FileHash .\ALETHEIA_*_x64-setup.exe -Algorithm SHA256
   ```

   - मिले हैश (SHA256) की तुलना `SHA256SUMS.txt` में उसी फ़ाइल की लाइन से करें।
   - **अपेक्षित परिणाम:** दोनों हैश बिल्कुल मेल खाते हैं। अगर मेल नहीं खाता, तो इंस्टॉल न करें — फ़ाइल दोबारा डाउनलोड करें।

3. **इंस्टॉलर चलाएँ:** `ALETHEIA_0.2.0_x64-setup.exe` पर डबल-क्लिक करें।
   - इंस्टॉलर अभी कोड-साइन नहीं है, इसलिए Windows SmartScreen *"Windows protected your PC"* दिखा सकता है। ऊपर हैश जाँचने के बाद **More info → Run anyway** चुनें।
   - **अपेक्षित परिणाम:** इंस्टॉलर विज़ार्ड खुलता है और इंस्टॉल पूरा होता है।

4. **ऐप लॉन्च करें:** स्टार्ट मेन्यू से **ALETHEIA** खोलें।
   - **अपेक्षित परिणाम:** ऐप डैशबोर्ड के साथ खुलता है। यह **सिमुलेशन मोड** में खुलता है — बिना किसी खाते या API कुंजी के सब कुछ काम करता है।

**वैकल्पिक: चैट असिस्टेंट के लिए स्थानीय AI मॉडल।**
[Ollama](https://ollama.com) इंस्टॉल करें, फिर PowerShell में चलाएँ:

```powershell
ollama pull mistral:7b
```

- **अपेक्षित परिणाम:** टर्मिनल में "success" संदेश दिखता है। मॉडल के बिना भी हर पेज और हर एजेंट रन काम करता है; सिर्फ़ चैट के लिए मॉडल (या क्लाउड कुंजी) चाहिए।

## 2. अपना पहला विश्लेषण चलाना

1. **पोर्टफोलियो बनाएँ:** बाईं ओर के मेन्यू में **Portfolio** पेज खोलें।
   - **हाथ से:** Symbol, Quantity और Average Price भरकर जोड़ें।
   - **CSV से:** [नमूना CSV](sample_portfolio.csv) डाउनलोड करें (या अपनी CSV बनाएँ जिसमें ये कॉलम हों: `symbol,quantity,average_price,asset_type,exchange,tax_profile`) और **Upload** बटन से उसे अपलोड करें।
   - **अपेक्षित परिणाम:** आपकी होल्डिंग्स पोर्टफोलियो टेबल में दिखती हैं।

2. **विश्लेषण शुरू करें:** ऊपर की पट्टी में **New Analysis** बटन दबाएँ।
   - "Run multi-agent analysis" डायलॉग में **Select Portfolio** ड्रॉपडाउन से अपना पोर्टफोलियो चुनें।
   - (वैकल्पिक) "Custom Analysis Prompt" में अपना सवाल लिखें, जैसे `Analyze portfolio long term drift`।
   - **Start run** बटन दबाएँ।
   - **अपेक्षित परिणाम:** ऐप आपको लाइव प्रोग्रेस स्क्रीन पर ले जाता है, जहाँ Collector, Oracle, Sentinel, Sage और Scribe एजेंट क्रम से काम करते हुए दिखते हैं।

3. **रिज़ल्ट पढ़ें:** रन पूरा होने पर आपको मिलता है:
   - प्रति-प्रतीक (per-symbol) सिग्नल और **BUY / HOLD / REDUCE** सारांश (confidence, stop-loss और target के साथ)।
   - पोर्टफोलियो **Value-at-Risk (VaR)** और सांद्रता (concentration)।
   - भारत-विशिष्ट **STCG/LTCG** टैक्स परिदृश्य।
   - (वैकल्पिक) रिज़ल्ट को **PDF या Excel** में एक्सपोर्ट करें।
   - **अपेक्षित परिणाम:** आपको एक पूरी लिखित रिपोर्ट मिलती है।

## 3. आपका डेटा कहाँ रहता है

सब कुछ स्थानीय रूप से संग्रहीत होता है — ऐप के इंस्टॉल फ़ोल्डर के अंदर एक `data` फ़ोल्डर में (`resources\aletheia-backend\data`)। कोई खाता, कोई क्लाउड, कोई टेलीमेट्री नहीं।

- किसी भी समय *Settings → Apps* से अनइंस्टॉल कर सकते हैं; आपका डेटा वहीं रहता है।
- उसी फ़ोल्डर में फिर से इंस्टॉल करने पर आप वहीं से शुरू करते हैं जहाँ आपने छोड़ा था।

## 4. महत्वपूर्ण नोट

- **शेयर डेटा की गति।** ब्रोकर कनेक्शन के बिना, भारतीय शेयर कोट्स विलंबित होते हैं; ऐप स्क्रीन पर यह बताता है।
- **सिग्नल रिसर्च आउटपुट हैं।** ये कीमत इतिहास और मॉडल से आते हैं; Signal Validation और अपने विवेक का उपयोग करें। यह वित्तीय सलाह नहीं है।
- **सुरक्षा।** कोई भेद्यता मिले तो निजी रूप से रिपोर्ट करें; [SECURITY.md](../SECURITY.md) देखें।

## 5. (वैकल्पिक) सोर्स से चलाना

अगर आप इंस्टॉलर के बजाय कोड से चलाना चाहते हैं, तो चाहिए: Python 3.13 + [Poetry](https://python-poetry.org), Node.js 20, और [Rust टूलचेन](https://rustup.rs) (Windows पर Visual Studio C++ Build Tools के साथ)।

पहला टर्मिनल (बैकएंड, पोर्ट 8899):

```powershell
poetry install
poetry run pip install maturin
cd aletheia_rust; poetry run maturin develop; cd ..
poetry run aletheia config init
poetry run uvicorn aletheia.core.main:app --port 8899
```

दूसरा टर्मिनल (फ्रंटएंड):

```powershell
cd frontend; npm ci; npm run dev
```

- **अपेक्षित परिणाम:** ब्राउज़र में `http://localhost:5173` खोलें — फ्रंटएंड यहाँ खुलता है (बैकएंड `http://localhost:8899` पर चल रहा है)।
- डेस्कटॉप शेल चाहते हैं? `cd desktop; npm ci; npm run tauri dev` चलाएँ।
